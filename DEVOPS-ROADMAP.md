## DevOps Learning Roadmap

Overview

A structured learning path covering the fundamentals of DevOps, automation, infrastructure, cloud computing, and modern deployment practices.

## Learning Roadmap

No.| Area| Main Topics
01| Git and GitHub| Version control, commits, branches, merging, remote repositories
02| Python| Programming fundamentals, functions, modules, automation
03| Linux and Shell Scripting| Linux commands, filesystem, permissions, Bash scripting
04| Networking and Security| IP addressing, DNS, HTTP/HTTPS, SSH, firewalls
05| Server Management| Nginx, web servers, reverse proxies, caching
06| Docker| Images, containers, volumes, networks, Docker Compose
07| Kubernetes| Pods, deployments, services, configuration
08| Infrastructure as Code| Terraform, providers, resources, state
09| CI/CD| GitHub Actions, automated testing, build and deployment pipelines
10| Monitoring and Observability| Prometheus, Grafana, metrics, logs, alerts
11| Cloud Computing| AWS fundamentals, core services, cloud deployment

Additional Topics: DevSecOps fundamentals and software engineering practices.

## Phase 1 — Foundation

Weeks 1–2: Git and Terminal Basics

Topics

- Git fundamentals
- Commits and repository history
- Branching and basic Git workflow
- Terminal navigation
- Creating and editing files

Primary Resource: "Learn Git Branching" (https://learngitbranching.js.org/)

Practical Milestone: Create a local Git repository, commit a file, and push it to GitHub.

Weeks 3–4: Core Python

Topics

- Variables and data types
- Conditional statements
- Lists and dictionaries
- Loops
- Functions

Primary Resource: "freeCodeCamp" (https://www.freecodecamp.org/)

Practical Milestone: Write a script that processes a list of numbers and prints values greater than 5.

Weeks 5–6: Python for Automation

Topics

- Python "os" module
- File and directory operations
- Copying, moving, and organising files

Resources

- "Corey Schafer — Python Tutorials" (https://www.youtube.com/@coreyms)
- "Automate the Boring Stuff with Python" (https://automatetheboringstuff.com/)

Practical Milestone: Build a script that moves ".txt" and ".log" files into a backup folder.

Weeks 7–8: Data and Networking Basics

Topics

- JSON and Python's "json" module
- HTTP requests using "requests"
- HTTP response status codes

Practical Milestone: Write a Python script that sends an HTTP request and displays its status code.

Phase 1 Graduation Project

Basic Website Status Checker

Develop a Python script that:

1. Sends an HTTP request to a local Nginx webpage.
2. Checks whether the response indicates success.
3. Writes a status message to "status.log" when the check fails.
4. Uses Python's "requests" and "os" modules.
